# HelloButton

Open `public/index.html` directly in a browser by double-clicking it or using the browser’s Open File command. The button switches between `Click me` and `Hello World` each time you activate it.

[https://hello.sheql.org/](https://hello.sheql.org/)

After setting up Playwright as described in [AGENTS.md](AGENTS.md), run `npm test` to check the local file. Set `HELLOBUTTON_URL` to check a different URL.
